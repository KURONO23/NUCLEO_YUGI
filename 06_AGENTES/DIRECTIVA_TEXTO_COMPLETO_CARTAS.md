# 06_AGENTES - DIRECTIVA INMUTABLE: FORMATO DE VISUALIZACIÓN DE CARTAS
*Regla estricta para todos los agentes del Núcleo.*

Cada vez que se muestre una carta en mano, campo o cementerio, se DEBE incluir de manera obligatoria:
1. **Nombre Oficial de la Carta** (en inglés y español).
2. **Nivel / Atributo / Tipo** (si es monstruo) o **Tipo de Magia/Trampa**.
3. **ATK / DEF originales** (si es monstruo).
4. **TEXTO COMPLETO Y EXACTO DEL EFECTO** (Prohibido resumir como "buscador", "burn" o "defensa"; se debe detallar cómo y cuándo se activa el efecto y cuál es su condición de resolución).
